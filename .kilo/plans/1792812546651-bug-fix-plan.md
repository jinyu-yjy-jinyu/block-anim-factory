# Bug Fix Plan (post-scan)

## Context
Full scan completed: 12 test suites pass, desktop smoke and Electron security tests pass. Engineering risks and known product issues remain. This plan lists executable follow-ups only; no source edits are made in plan mode.

## Scope
- In scope: CI/release engineering defects, test coverage gaps, version synchronization, and high-value product defects already documented in README.
- Out of scope: large platform features (cloud render, CRDT sync, ASR, true LLM integration, macOS/Linux shells) unless separately requested.

## Ordered Tasks

- Add a workflow (extend `desktop.yml` or create `desktop-electron.yml`) that:

  - sets up Node 20
  - installs dependencies in `desktop-electron/`
  - runs `smoke.mjs`, `test-asar-path.mjs`, `test-encoding.mjs`, `test-server-security.mjs`
- Keep relative imports already fixed.
- Validation: workflow green on a PR.

### 2. Version synchronization guard
- Add `scripts/check-version.mjs` comparing:
  - `package.json` version
  - `desktop/BlockAnim.csproj` `<Version>`
  - `desktop/installer.iss` `AppVersion`
- Add CI step in both `ci.yml` and `desktop.yml` to fail on mismatch.
- Validation: intentionally mismatch one file locally and confirm failure.

### 3. Orphan test disposition
- Decide and document for `test-gif.mjs` and `test-mp4.mjs`:
  - Option A: integrate into `scripts/test-all.mjs` and add npm scripts (`test:gif`, `test:mp4`).
  - Option B: remove/archive if obsolete.
- If integrated, ensure browser availability guard remains.
- Validation: `npm test` includes them without flakiness.

### 4. npm scripts completeness
- Add missing scripts for any retained orphan suites.
- Keep `test:markdirty` and `test:renderer-img` already added.
- Validation: each script runs independently.

### 5. Product defect: GIF color shift
- Investigate quantization/palette and dithering in `src/gif.js`.
- Add regression assertion in `test-pipeline.mjs` or `test-gif.mjs` for color error threshold.
- Validation: existing GIF structural tests still pass and new color assertion passes.

### 6. Product defect: deep nesting silent stall
- In evaluator/render loop, surface a user-visible warning when frame step limit is hit.
- Add state flag or console/UI hint; avoid changing rendering semantics.
- Validation: nested-loop test reproduces warning.

### 7. Product defect: audio not rolled back with versions
- Extend `src/collab.js` snapshot/restore to include audio track state, or document as intentional limitation.
- If implemented, add regression test in `test-v3v4.mjs`.
- Validation: rollback restores both visuals and audio.

### 8. Product defect: legacy particle/repeater parameters
- Add migration logic for old saved projects or document manual reconfiguration.
- Validation: load old project fixture and verify parameters.
